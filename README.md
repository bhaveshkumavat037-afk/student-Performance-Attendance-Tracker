# Student Performance & Attendance Tracker

## Project Overview
A comprehensive MySQL database solution designed to track student performance, record attendance, manage course enrollments, and analyze marks using advanced SQL operations.

## Features & Implementation
- **Schema Design**: 7 relational tables with Foreign Keys & Constraints
- **CRUD Operations**: Data insertion, updating details, and record management
- **Advanced Joins**: INNER JOIN, LEFT JOIN, RIGHT JOIN
- **Aggregation & Sorting**: GROUP BY, ORDER BY, HAVING, and Aggregate Functions
- **Advanced Logic**: Subqueries, String & Date functions, Window Functions, and CASE Statements

## File Structure
- `student_tracker.sql`: Complete MySQL script containing database schema, sample data, and all functionality queries.
